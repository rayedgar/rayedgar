# Elementor XR Widget

Adds a custom 'XR' tool to Elementor with text input, typography options, and color controls.

## Installation

### Method 1: Upload via WordPress Admin
1. Download or compress the `elementor-xr-widget` folder into a `.zip` file (e.g., `elementor-xr-widget.zip`).
2. Log in to your WordPress Admin dashboard.
3. Go to **Plugins > Add New**.
4. Click **Upload Plugin** at the top.
5. Choose the `elementor-xr-widget.zip` file and click **Install Now**.
6. Once installed, click **Activate Plugin**.

### Method 2: Manual Installation via FTP/SFTP
1. Upload the `elementor-xr-widget` folder to the `/wp-content/plugins/` directory on your server.
2. Log in to your WordPress Admin dashboard.
3. Go to **Plugins > Installed Plugins**.
4. Find **Elementor XR Widget** in the list and click **Activate**.

## Requirements
- **Elementor**: Version 3.0.0 or greater must be installed and activated.
- **PHP**: Version 7.0 or greater.

## Usage
1. Open any page or post with the **Elementor Editor**.
2. Search for the **XR** widget in the widgets panel (General category).
3. Drag and drop the **XR** widget into your layout.
4. Use the **Content** tab to edit the text and adjust the **Text Color** and **Typography** settings.
